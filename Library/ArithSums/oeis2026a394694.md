# OEIS A394694

The first-tier 2026 OEIS conjecture reads verbatim:

> Conjecturally: a(n) = A000005(n-1)/2 + e(n), where e(n) = 1/2 if n-1 is a perfect square, 1 if n-1 is pronic, and 0 otherwise.

The counted triangle is A081493. Its formula, attributed to David Wasserman
on June 3, 2004, is `T(i,j) = i + (i-1)*(j-1)`, with `1 <= j <= i`.
For `n >= 2`, put `m = n-1`: occurrences correspond to positive factor pairs
`d*b = m` with `b <= d+1`. The index `n = 1` must be handled separately.

## Preregistered Proof Obligation

Before implementation, the proposed escape witness is the small-divisor
classification: if `d` divides positive `m` and `d*d < m`, then
`m <= d*(d+1)` holds exactly when `m = d*(d+1)`. Such a divisor is unique
and is the integer square root of `m`. This is to be used on the active proof
path in the divisor count, then transported to the bounded triangle count.
The bind-only attempt must precede construction of a module.
