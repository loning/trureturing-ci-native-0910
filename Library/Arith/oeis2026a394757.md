# OEIS A394757

The OEIS entry defines the sequence using twin-prime centers `k` for which
`gcd(k, sigma(k))` is prime, and records the divisibility assertion addressed
by the Lean module. The formal theorem uses the corresponding natural-number
definition and supplies a proof for every `k`.
