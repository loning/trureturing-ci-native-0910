# Global patterns in signed permutations

Levens, Lewis, and Tenner define global containment for signed permutations in
Definition 2.4: the occurrence indices range over the full signed order, while
the contained pattern is unsigned and the selected values are
order-isomorphic to it. Definition 4.1 calls a property persistent when its
type-B elements are characterized by global avoidance of the same patterns
that characterize the property in type A.

This note attests only those two definitions. It does not attest the repository's
negative answer to the persistence question in Section 6.1.
